# Перевод уведомлений на новый маршрутизатор

## Рекомендация

Предлагаем согласовать пробное включение нового маршрутизатора для тестовых команд. Он повторяет доставку после временного сбоя получателя.

## Как пройдёт пилот

Дежурный включит новый маршрутизатор для двух тестовых команд. События пилота будут видны в журнале доставки.

## Что проверили

На стенде маршрутизатор доставил уведомления после восстановления получателя. Проверку под нагрузкой, близкой к рабочей, ещё не проводили. Решение о полном переключении примем по её результату.

## Справка

Старый маршрутизатор использует те же адреса получателей. Правило выбора канала описано в инструкции по настройке уведомлений.
