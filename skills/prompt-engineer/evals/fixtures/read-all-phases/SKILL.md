# Read all phases

Фикстура для линта. Скелет читает все фазы сразу. Второй шаг спрятан за вложенной ссылкой.

## Preconditions

- [ ] Путь к цели передан в аргументах.

## Алгоритм

Перед стартом прочитай все файлы в `phases/` и `references/`.

1. Сверь имя файла цели. Шаг короткий и выполняется всегда.
2. Прочитай `references/router.md` и иди по ссылке внутри него.

## Hard Stop Rules

- Не пиши в цель, пока не прочитаны все файлы фаз.

## Definition of Done

- Оба шага выполнены, отчёт записан.

## Пример

Вход: «разбери phases». Результат: отчёт по шагам 1 и 2.

## Команды проверки

```bash
test -f phases/step-1.md
```

## Gotchas

- Не пропускай чтение всех файлов в начале.

## Scope

In: пофазный разбор. Out: публикация.
