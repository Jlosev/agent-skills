# Хуки Claude Code для /pipeline

Ставятся один раз глобально, работают во всех проектах. Хук молчит, пока в сессии не идёт прогон `/pipeline`.

Состояние и ручное возобновление прогона работают в любом харнессе. Хуки добавляют автопродолжение там, где харнесс поддерживает его.

Для подключения своего харнесса передай его ID через `PIPELINE_SESSION_ID` при preflight. Адаптер события вызывает `pipeline.py hook` и передаёт в stdin JSON с `hook_event_name: "Stop"`, `cwd` и тем же `session_id`. Если харнесс умеет сообщать о фоновых задачах, передай их в `background_tasks`. Ответ с `decision: "block"` и `reason` адаптер преобразует в штатное продолжение хода. Пустой ответ разрешает остановку. Если адаптер не подключён, возобнови фазу вручную по state.

## Что делает `pipeline.py hook`

| Событие | Условие | Действие |
|---|---|---|
| `Stop` | найден state (сначала `.pipeline/` своего worktree, потом главного checkout, потом `.cursor/pipeline/`; закоммиченный в git не считается), `phase` не `done` и не `clarify`, `blocked` пуст, сессия – владелец прогона (`state.session`, иначе транскрипт вызывал `/pipeline`), `background_tasks` пуст | `{"decision":"block"}`: продолжай по state |
| `Stop` | то же, но нет прогресса (`updated` и `HEAD` те же) после 2 блоков подряд или 6 блоков за фазу | отпускает ход, прогон можно возобновить по сохранённому state |
| `StopFailure` (ошибка API: лимит, сервер, обрыв) | активный прогон | прогон можно возобновить по сохранённому state |
| прерывание пользователем (Esc) | — | хук не вызывается, остановка всегда возможна |

Обёртка хука сохраняет возможность остановить ход при сбое.

## Установка

`~/.claude/settings.json`:

```json
{
  "hooks": {
    "Stop": [{ "hooks": [{ "type": "command", "command": "f=~/.agents/skills/pipeline/scripts/pipeline.py; [ -f \"$f\" ] && python3 -I \"$f\" hook; exit 0", "timeout": 20 }] }]
  }
}
```

`exit 0` в конце обязателен: для `Stop` код 2 значит «блокировать», и без него пропавший скрипт держал бы каждую сессию. Если блок `hooks.Stop` уже есть – добавь элемент в массив, не заменяй.

## Проверка

```sh
bash ~/.agents/skills/pipeline/scripts/test_pipeline.sh   # самопроверки preflight, diff-guard, hook
```
